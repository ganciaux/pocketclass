# Entraînement (phase 2) — plan

> Exécution inline, TDD sur le pur. Points de validation avec l'utilisateur après les tâches 2
> et 4.

**Goal:** short practice series on a sheet (formula A), new exercise types, scores for the
parent; then the timed challenge (formula C). **Spec:**
[2026-11-25-practice-design.md](../specs/2026-11-25-practice-design.md).

## Global constraints

- Code in English, UI text in `fr.ts`; child pages read `session.childView`, write on `ownerId`.
- Rules change ⇒ case in `tests/rules/firestore.rules.test.ts`. Child writes via `inBackground()`.
- Existing sheets stay valid (additive format change). No push, no deploy unless asked.

## Review focus

- Answer checking is lenient on accents / case / spaces but never accepts a wrong value
  (fractions compared by value, irreducibility enforced when required).
- A series never contains `assessment` or `generator` exercises; it works with 1 exercise.
- Offline: finishing a series writes the attempt + progress without waiting for the network.

### Task 1: format

- `schemas/common.ts`: `match`, `true_false`, `categorize` variants, `explanation` in the base;
  cross-checks (categorize category ∈ categories, unique pair sides). Tests.
- Prompt (`prompts/sheetPrompt.ts`): new types, ~4 practice per key point, 8–10 true/false,
  explanations. Sample `maths-3e-revisions.json` gains examples of the new types.
  `npm run schemas`. Commit `feat(sheets): match, true/false, categorize and explanations`.

### Task 2: pure engine (`src/lib/practice/`)

- `answers.ts`: `normalizeText`, `checkAnswer(exercise, response)` per type (calculation via
  `math/fraction.ts`). `series.ts`: `playable(exercises)`, `buildSeries(exercises, size, rng)`
  (round-robin by key point), `scoreOf(results)`, `wrongOnes(results)`. Tests first.
- Commit `feat(practice): answer checking and series`. **Checkpoint.**

### Task 3: data + rules

- Types `AttemptRecord`, progress `practiceLast/Best/At`; `refs.ts` attempts; `data/practice.ts`
  (`watchPlayableExercises`, `saveSeries` = one batch, `inBackground`); test reset clears
  attempts. Rules + tests. Commit `feat(practice): attempts and scores`.

### Task 4: player UI

- `components/exercises/*` (one per type, contract `onanswer({ correct, response })`),
  `ExercisePlayer`, `AnswerFeedback`; route `/concept/[id]/practice` (series → feedback →
  result, retry wrong). Commit `feat(practice): series player`. **Checkpoint.**

### Task 5: wiring

- Sheet page button + scores; parent profile « Entraînement » card. `fr.ts`, CLAUDE.md,
  backlog. Verify + browser. Commit `feat(practice): scores on the sheet and for the parent`.

### Task 6: timed challenge (formula C)

- Planned after task 5 validation (own short spec addendum).
